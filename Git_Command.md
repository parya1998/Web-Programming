## Clone Repo
On CLI <b>git clone (url)<b>

## Track file Locally
- Create a file
    <br>```touch hello.html``` - for creating file
- Add file for tracking <br>
    ```git add <filename>``` - for single file
- Save it aka Commit (savepoint / checkpoint)<br>
    ```git commit -m "Your message"``` = for saving the file
- Update the git repo on server <br>
    ```git status``` = check the file update status.<br>
    ```git push```
